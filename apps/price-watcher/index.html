Competitor Price Watcher

Track competitors’ prices for the products you sell. A free GitHub robot checks their public product pages every day, keeps a price history and emails you when a price moves. Then load that history here to see charts, who is undercutting you and every change.

This page doesn’t visit any website and doesn’t send your list anywhere — it only writes files for you to copy. Your settings are saved in this browser.

Why GitHub, and not this page?

A web page can’t read other shops’ websites (browsers block that) and can’t run while it’s closed. So this page writes three small files and GitHub Actions runs them free on GitHub’s computers once a day. You need a free GitHub account; no coding and no credit card.

  • How it reads prices: most shops publish the price in hidden “structured data” for Google (JSON-LD or meta tags), so usually you only paste the product page address. If that fails, add a CSS selector — use the Test a page tab to find one.
  • Be polite and legal: it checks one page at a time, a few seconds apart, says who it is in its user agent, and skips pages that the site’s robots.txt asks tools not to visit. Only watch public pages, read each site’s terms of use, and don’t check more often than you need — once a day is plenty.
  • Honest limits: pages behind a login, a CAPTCHA or strong bot-blocking won’t work. Prices built only by JavaScript may need the “needs a real browser” option (slower). Scheduled runs can start 5–30 minutes late; a public repository with no activity for 60 days pauses its schedule until you re-enable it.

What should it watch?

Use the same Group name for your product and the competitors selling the same thing, and tick “This is mine” on yours — that’s how undercuts are found.

Put it on GitHub (about 10 minutes)

  1. Go to github.com and sign in (or create a free account).
  2. Click + (top right) → New repository. Name it e.g. price-watcher. Choose Private if you don’t want others to see your competitor list, tick Add a README file, then Create repository.
  3. Click Add file → Create new file. Type the name .github/workflows/price-watcher.yml (typing / makes the folders). Paste the Workflow file, then Commit changes… → Commit changes.
  4. Again Add file → Create new file: name watcher/watch.js, paste watch.js, commit.
  5. Once more: watcher/products.json, paste products.json, commit.
  6. Open Settings → Actions → General. Under Workflow permissions choose Read and write permissions → Save. (This lets it save prices.csv and open issues with GitHub’s own token — no passwords.)
  7. Open the Actions tab (click I understand my workflows… if asked) → Price watcher → Run workflow. After about a minute, open the run: the log lists each product and the price found. Fix any “not-found” rows by adding a selector.
  8. To get emails when prices move, click Watch at the top of the repository → Custom → Issues.
  9. Later, open watcher/prices.csv on GitHub, click Download raw file (or copy the page address if the repository is public) and load it in 2. Analyse prices.

To stop: Actions → Price watcher → ••• → Disable workflow. A private repository uses free Actions minutes (2,000 a month); one daily check uses well under a minute.

Will the tracker find the price on this page?

  1. Open the competitor’s product page in your browser. Right-click → View page source (or press Ctrl+U / ⌥⌘U).
  2. Select all (Ctrl+A / ⌘A), copy, and paste it below. Nothing is sent anywhere.
  3. Leave the selector empty first. If no price is found, right-click the price on the real page → Inspect, note its class (e.g. class="price-now") and try .price-now.

Supported selectors: tag, .class, #id, [attr], [attr=value], [attr*=part], combined (span.price.now) and nested (.product .price). Add @attribute to read an attribute, e.g. #price@data-price.
