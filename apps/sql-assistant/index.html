SQL Assistant

Paste a query to tidy it up, read what it does in plain English, and catch slow or risky patterns — like an UPDATE with no WHERE — before you run it.


    

  

  


  
Your SQL stays in your browser — nothing is sent to a server or run against a database. The checks are fixed rules (no AI) and can’t see your indexes or data sizes, so treat them as hints. If you turn on the optional AI helper, the ✨ button sends only the SQL to the AI you chose.
