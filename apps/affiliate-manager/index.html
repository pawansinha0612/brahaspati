In Australia the ACCC expects you to clearly disclose paid or affiliate relationships (misleading conduct under the Australian Consumer Law); the US FTC and UK ASA have similar rules. Put the disclosure before the first link, in plain words — not hidden at the bottom or only in a hashtag cloud.

Check your links automatically (optional)

This page can’t open your affiliate links to see if they still work — browsers block reading other websites. Instead, you can let GitHub do it free every week: it follows each link and opens an issue (which emails you) when a link errors, or lands on the shop’s home page instead of the product.

  1. Create a free private repository on github.com (tick “Add a README”).
  2. Add file → Create new file: .github/workflows/link-check.yml — paste the workflow. Commit.
  3. Create links/check-links.js and links/links.json the same way.
  4. Settings → Actions → General → Workflow permissions: choose Read and write, Save. Then Actions → Affiliate link check → Run workflow.
  5. When you add links here, copy a fresh links.json to GitHub. After a check, mark links as checked on the Links tab.
