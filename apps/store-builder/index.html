Download

The zip has index.html, an images folder and a README. The single file has the images built in (bigger, but one file).

Put it online free

  1. Netlify Drop (quickest): unzip the download, open app.netlify.com/drop and drag the folder onto the page. Make a free account to keep it.
  2. GitHub Pages: create a free public repository on github.com, click uploading an existing file, drag in index.html and the images folder, commit. Then Settings → Pages → Deploy from a branch → main / root → Save. Your shop appears at https://your-name.github.io/repository-name/.
  3. Paste that address into Store web address on the Store tab and download again, so Google and link previews get the right URL.
