What this can and can’t do

  • Can: CSV ⇄ TSV ⇄ JSON ⇄ Excel (.xlsx, any sheet) ⇄ Markdown table ⇄ HTML table, and any table → SQL INSERT statements. Nested JSON is flattened to columns like user.address.city, and “JSON (nested)” rebuilds the nesting from those dot paths.
  • Can: PDF → plain text, Word (.docx) → text, HTML or Markdown (headings, lists, bold, links and tables are kept).
  • Can’t: make a real PDF file directly. Use “Print / save as PDF” and choose “Save as PDF” in your browser’s print window.
  • Can’t: keep Excel formulas, formatting, charts or merged cells — only the values. Old .doc (Word 97) files and scanned PDFs are not supported; images in Word files are left out.
  • Can’t: convert to Word, PowerPoint, images or YAML.

Your files stay on your device. Everything is converted inside this browser tab.
