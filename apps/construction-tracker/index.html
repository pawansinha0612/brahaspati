Construction Project Tracker

Plan stages on a timeline, keep contractors' licences and insurance current, chase late deliveries, log delays and variations, write the site diary with photos, and see budget against actual by cost code — then print a progress report for the client.

How it works and its limits
  • Progress is each stage's % complete, weighted by how many days the stage runs. "Planned by today" assumes work runs evenly through each stage.
  • Actual = costs you enter. Committed = orders marked Ordered or Delivered. When the supplier's invoice arrives, enter it under Costs and set the order to Invoiced so it is not counted twice.
  • Contract value = original price + approved variations. Variations signed by the client on screen are marked Approved.
  • Licence, insurance and workers' comp reminders show here and in the .ics calendar file. Always check licences on your state regulator's register — this tool cannot look them up.
  • This is a simple tracker, not a scheduling engine: stages do not move automatically when something is late.
