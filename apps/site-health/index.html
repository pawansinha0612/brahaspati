Use your own free Google key (recommended)

Tests run on Google's free PageSpeed Insights service. Without a key you share a small daily limit with everyone else, and it is often used up. A key of your own is free and allows about 25,000 tests a day.

  1. Open PageSpeed Insights: get a key and press Get a Key (sign in with any Google account).
  2. Copy the key (it starts with AIza) and paste it below.
  3. Optional but wise: in Google Cloud → Credentials, restrict the key to the PageSpeed Insights API.

The key is stored only in this browser and sent only to Google with each test.

The address you type is sent to Google's PageSpeed Insights service to be tested. Nothing else leaves your browser.

Security headers

Why you need to paste: browsers deliberately stop one website from reading another website's security headers (this is called CORS), so this page cannot fetch them for you. Run the command below in Terminal (Mac/Linux) or PowerShell (Windows 10+, type curl.exe), then paste what it prints.

curl -sIL 'https://yourbusiness.com.au/'

No terminal? In Chrome, open your site, press F12 → Network → click the first row → Headers → copy the "Response Headers".
