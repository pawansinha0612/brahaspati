Architecture Diagram Generator

Describe your system in a sentence or two — or paste a docker-compose file, Kubernetes YAML or a folder tree — and get a layered architecture diagram you can edit, then export to SVG, PNG, Mermaid or draw.io.

Name the parts (“orders service”, “Postgres”, “Kafka”, “React web app”, “Stripe”) and say how they talk: calls, routes to, reads from, writes to, publishes, consumes, through.

Reads services, images, ports, depends_on, links, networks, named volumes and hostnames inside environment values (e.g. postgres://db:5432).

Paste one or more YAML documents separated by ---. Links Ingress → Service → Deployment/StatefulSet by selectors, plus ConfigMaps, Secrets and volume claims.

Paste the output of tree -L 3 (or an indented list). Spots frontend, backend, worker, mobile, database-migration and infrastructure folders. It guesses from folder names only.

    Everything runs in your browser — your YAML and descriptions are not uploaded. The diagram library (Mermaid) is downloaded once from a public CDN. The rules match common names and verbs, so check the result and fix the Mermaid text if something’s off.
