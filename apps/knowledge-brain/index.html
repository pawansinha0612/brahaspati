Your library

Uses the same “Look in” filter as Search. Without AI, the answer is made of the best-matching sentences from your documents, each with a numbered source.

Where does my data go?

  • Without AI: nowhere. Reading, indexing, searching and answering all happen in this tab, and the library is saved in this browser’s own storage.
  • With the in-browser model (AI settings → “local”): the model runs on your computer, so nothing leaves the device either. The first use downloads the model (about 1 GB) once.
  • With a Gemini key: only the question and the few best-matching passages are sent to Google to write the answer.

Back up or move your library

Your library lives only in this browser. Export it as one JSON file to keep a copy or open it on another computer.
