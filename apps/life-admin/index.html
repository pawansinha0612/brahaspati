Life Admin Vault

Passports, visas, licences, Medicare, insurance, rego and certificates for everyone in the family — with what’s expiring, when to start renewing, calendar reminders and a printable emergency summary.

Everything stays on this device — nothing is uploaded. By default only the last 4 characters of ID numbers are kept. Clearing your browser data deletes it all, so download a backup (Backup tab).

What needs doing

The calendar file has a “start renewing” event on each renew-by date and an event on each expiry date (with an alert a week before). Re-download it after you add or renew documents.

Passport check for a trip

Many countries need your passport valid for at least 6 months beyond your stay. Always check the rules for each country you visit (search “Smartraveller” plus the country).

Emergency summary

A printable page with each person’s medical notes, emergency contacts and documents (numbers masked unless you chose to keep them in full). Useful on the fridge, in the car, or with a carer.

Renewal checklists

General steps only — rules differ by state and change over time, so always check the official website.

Backup

One file with every person, document and attached photo. It contains personal information — store it somewhere private (for example an encrypted USB drive or a password-protected folder). Restoring replaces what is here now.
