Renames the files directly inside the chosen folder (not sub-folders). Nothing changes until you press Apply.

Moves the files directly inside the chosen folder into sub-folders. Files already in sub-folders are left alone.

Checks the folder and all its sub-folders. Files are first grouped by size, then only same-size files are read and fingerprinted (SHA-256), so two files only count as duplicates if their contents are byte-for-byte identical. Names don’t matter.

The oldest copy in each group is left unticked (kept). Deleted files skip the Recycle Bin / Bin, so double-check first.

    Can this run every day by itself?

    Not from a web page. Browsers only run a page while it is open, and they never let a website touch your folders without you clicking first. So there are two honest options, both free:

    1. Your own computer runs a small script on a timer (cron on macOS/Linux, Task Scheduler on Windows). The script below is generated from your Organise settings and works on whatever files are in the folder at the time.
    2. GitHub Actions runs a script on GitHub’s computers on a timer. It can only work on files stored in a GitHub repository (for example CSV exports you commit), not on your own disk.
